# Koch 自动搬运回放

自动搬运根据 S 区库存和 T 区任务卡选择已采集的关节轨迹，核对相邻轨迹的衔接，再顺序回放。ACT 模型窗口、手动采集和单条回放仍使用各自的原入口。

## 配置和启动

在项目根目录激活 Python 环境后，复制 [现场配置示例](../replay-auto.site.example.json) 为 `replay-auto.site.json`。按现场填写相机、从臂串口和 T 区旋转角度。示例中的相机号与角度是占位值。

- `data` 指向包含四个 `koch_st` 系列目录的数据根目录。配置文件中的相对路径从该文件所在目录解析。
- `source.config` 指向 S 区八面标定。自动回放需要同视角的空台面参考，用于识别空位和检查最终库存。
- `targets.config` 指向 T 区纸面颜色、数字模型和数字复核配置。参考 [视觉配置示例](../configs/grid_runtime.example.json)。配置中的资源路径优先从配置所在目录解析，同时兼容现有项目相对路径。
- `quantity_rule` 可用 `parity` 或 `direct`。前者把奇数读为一块、偶数读为两块，后者直接读取 0–2 块。

```powershell
python -m koch_autonomy replay-audit --data datasets
python -m koch_autonomy replay-plan --input examples/task.example.json --quantity-rule parity --output outputs/replay_plan.json
python -m koch_autonomy replay-run --plan outputs/replay_plan.json --step 1
python -m koch_autonomy replay-auto --site replay-auto.site.json --preview
python -m koch_autonomy replay-ui --site replay-auto.site.json
```

`replay-audit` 检查路线、完成标记、关节日志和编码器单位。`replay-plan` 给各步骤绑定示范并记录文件哈希。`replay-run` 省略串口与校准参数时只做单步离线核对。整组接缝由自动回放预览单独检查。

用「仅识别预览」核对识别和轨迹接缝。预览不会打开串口。实机开始前，操作人员在界面确认 T 区为空、从臂在录制时的共同起点且活动范围已清空。运行时可点击停止或按 Esc。

回放使用原控制器的限速、起点容差和停机保护。接缝校验依据相邻示范的关节目标，启动时仍以实际反馈核对。回放结束会重新读取 S 区。最终清空确认只反映 S 区库存，T 区放置结果仍需核对。

## 常见阻塞

- **找不到回放或权重**。检查数据根、清单和目录结构。参数版示范可做轨迹审计，视觉训练和依赖示范图像的探针需要配套影像。
- **接缝超过容差**。核对相邻示范终点、起点及从臂实测姿态。公共位不同的示范需要复核或重录。
- **卡片无法稳定确认**。核对相机取景、照明、颜色配置、两份数字模型与 T 区裁剪范围。
- **轨迹完成，S 区仍有库存**。检查现场抓放与 T 区落点。流程不会自动重放失败动作。
